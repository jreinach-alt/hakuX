## The measurement

`pgraph_vk_bind_textures` counted per bind, keyed by capture and swatch.
`trace_nv2a_pgraph_surface_texture_compat_failed` (`vk/texture.c:1806`) is
already on that path. Before counting, name what each exit would read for

refute a candidate rather than just describe the run.

## Falsifier

If the collapse is a reused binding, the collapsing swatches take the same
exit as swatch 0 and `SCF_X1R5G5B5_O1R5G5B5`'s swatches do not. If
`X1R5G5B5` takes the same exit as the collapsing formats, the exit is not
the discriminator. Say so plainly: that refutes this reading and moves the
question to the upload path.
