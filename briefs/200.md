## Goal

pgraph.c produce what silicon holds: the constant bits (SURFACE 0, TEXFMT 4-5)
at their init, the toggling ones (CONTROL_3 0x20, SETUPRASTER, CSV0_D FOG_MODE,
CSV1_A) from the same guest method the console derives them from. Read the
per-register "example: console vs hakuX, same test" column in the PR #254 doc
to find which test moves which bit; derive the source method from the register
diff, not from a guess. Rendered output must not move.
