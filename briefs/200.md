## What's already settled -- do not redo this

A prior board tick (2026-09-20) already checked the DIMENSIONALITY
width-mismatch the issue offered as its leading explanation, by reading
DEF_METHOD(NV097, SET_TEXTURE_FORMAT) (pgraph.c:4058-4090) and GET_MASK/
SET_MASK (nv2a_regs.h:25-33), then running SET_MASK(0,0xC0,dim) for all 16
guest nibble values: SET_MASK shifts by ctz32(0xC0)=6 and masks to 0xC0, so
only the guest nibble's LOW two bits (4-5) ever reach the register, landing
at TEXFMT0 bits 6-7 (the DIMENSIONALITY field itself) -- never at bits 4-5.
The width mismatch is REFUTED as the mechanism for the measured TEXFMT0
bits-4-5 divergence specifically (see nv2a_issues.toml issue.200
status_note, CORRECTED entry). Do not re-derive this; cite it.

The broader thesis -- every bit nv2a_regs.h does not declare is
structurally unreachable, because handlers only PG_SET_MASK against named
fields -- is UNAFFECTED by that refutation and is still open. That is this
brief's whole goal.

Separately, PR #201 (audit in progress) measured the same broader claim
empirically per-test: the emulator moved 24 registers (all declared), the
console moved 336 (only 28 declared). Read that PR's
docs/testing/pgraph-per-test-emulator-vs-hardware.md before starting --
this brief is the STATIC half of the same question, not a repeat of it.

## Goal

Enumerate every PG_SET_MASK call in pgraph.c's method handlers against
nv2a_regs.h's declared field masks, per register, to find every bit left
permanently at its init value because no handler writes it -- not just the
two registers (NV_PGRAPH_SURFACE, NV_PGRAPH_TEXFMT0/1) the issue already
named. Report as a table: register, declared mask, bits covered by a
handler write, bits left permanently unreachable.

## Falsifier

A register whose every handler-write path covers 100% of its declared mask
is evidence against "structurally unreachable" being widespread; report the
ratio (registers with at least one unreachable declared bit) / (registers
written by any handler), not just the raw count. If that ratio is small,
say so plainly -- that narrows the thesis rather than confirming it.
