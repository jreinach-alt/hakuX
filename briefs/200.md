## What's already measured

The issue traced two register disagreements (NV_PGRAPH_SURFACE bit 0,
NV_PGRAPH_TEXFMT0/1 bits 4-5) to method handlers that reconstruct registers
field-by-field via PG_SET_MASK, so any bit outside a declared field never
leaves zero. It also flags a width mismatch in the same handler:
NV097_SET_TEXTURE_FORMAT_DIMENSIONALITY reads a 4-bit guest value (mask
0x000000F0) into NV_PGRAPH_TEXFMT0_DIMENSIONALITY's 2-bit field (mask
0x000000C0) -- offered as the leading explanation, not proven. Separately,
PR #201 (open, needs-audit-1, not yet folded) measured the same claim
empirically per-test: the emulator moved 24 registers (all declared), the
console moved 336 (only 28 declared). Read that PR's
docs/testing/pgraph-per-test-emulator-vs-hardware.md before starting --
this brief is the STATIC half of the same question, not a repeat of it.

## Goal

Two things, both reading only:

1. Confirm or refute the DIMENSIONALITY width-mismatch mechanism by reading
   DEF_METHOD(NV097, SET_TEXTURE_FORMAT) (pgraph.c:4058) against
   NV_PGRAPH_TEXFMT0_DIMENSIONALITY's declared mask in nv2a_regs.h.
2. Enumerate every PG_SET_MASK call in pgraph.c's method handlers against
   nv2a_regs.h's declared field masks, per register, to find every other
   bit that is structurally unreachable the same way -- not just the two
   registers the issue already found. Report as a table: register, declared
   mask, bits covered by a handler write, bits left permanently at their
   init value.

## Falsifier

For the DIMENSIONALITY claim: if the 4-bit guest value is NOT masked down
to 2 bits before or during the PG_SET_MASK write (e.g. if an intermediate
shift or a different constant is actually used), say so -- that refutes the
issue's own leading explanation. For the enumeration: a register whose
every handler-write path covers 100% of its declared mask is evidence
against "structurally unreachable" being widespread; report the ratio
(registers with at least one unreachable declared bit) / (registers written
by any handler), not just the count.
