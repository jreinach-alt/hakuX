# lane.pmc188 -- issue #188

Base: master @ 20e4708d50. Files: hw/xbox/nv2a/pmc.c, hw/xbox/nv2a/nv2a_regs.h.

## Goal

`hw/xbox/nv2a/pmc.c:pmc_read` has no case for `NV_PMC_ENABLE` (0x200) and
falls through to `default: r = 0;`. Two independent read-only sweeps on real
NV2A silicon (reboot between them, 1,024/1,024 dwords reproducible) read
**0x01110000** there, not 0. Model the read.

Do **not** model the write side beyond what is already there (silent
no-op via `default:`). Writing 0 to this register **halted the physical
console** in the sweep that found it; #188 is explicit that the bit-field
semantics (which bits gate PFIFO/PGRAPH, whether `nv2a_regs.h`'s
`_PFIFO`/`_PGRAPH` positions even apply to NV2A) are NOT established and
need an envytools cross-reference this brief does not ask for. Scope is:
make the read match measurement. Do not add write-triggered halts or
engine-disable side effects -- that would need the semantics this brief
explicitly does not claim.

## Change

Add a `NV_PMC_ENABLE` case to the `switch (addr)` in `pmc_read` returning
the constant `0x01110000`. If `NV_PMC_ENABLE` is not already `#define`d in
`nv2a_regs.h` (the issue says it is declared with bit fields, at line ~72),
reuse that; do not invent new bit-field macros for the unconfirmed
semantics -- a bare constant return is enough and honest about what is and
isn't known.

## Falsifier

A unit/selftest read of offset 0x200 through `pmc_read` must return
`0x01110000`, not 0. Show it failing against current `pmc.c` first (the
`default:` path returns 0), then passing after the change. Also confirm
`pmc_write` behavior is byte-for-byte unchanged (grep the diff -- if
`pmc_write` has any hunk, that's out of scope).

## Done when

- `pmc_read(NV_PMC_ENABLE)` returns `0x01110000`.
- `pmc_write` is untouched.
- Falsifier committed and shown red-then-green in the PR.
- PR body cites this measurement and #188, and says explicitly that bit
  semantics remain unmodelled/unconfirmed (do not let the PR read as if the
  bitfield question was settled).
