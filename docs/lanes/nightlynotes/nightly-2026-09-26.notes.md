Automated nightly. built from `6550967a5e` on `master` (the tip of `origin/master`).

### Performance

- Grabbed by the Ghoulies no longer slows to 2 fps after a few minutes; it holds about 29 fps on handhelds (#311).

### Stability

- Games whose vertex programs write to constant registers no longer abort, and get the values the console computes (#233).

### Rendering fixes

- Pixel shaders using the DOT_ZW depth mode, and G8B8 surfaces, now render with the right depth and byte order (#279, #285).
- Vulkan: a texture no longer keeps showing a previous surface's image after the surface it samples changes (#274).
- Vertex colours that compute to NaN now draw as the console draws them (#281).
- Sphere-mapped textures on the R coordinate now render correctly (#273).
- Fixed-function geometry with vertices at extreme or infinite positions now draws as on the console (#223).
- The far part of floors and walls drawn with a 24-bit depth buffer no longer goes missing (#266).
- Vulkan: geometry a game updates by rendering into its own vertex memory no longer draws stale (#262).
- Vertex programs that write the position and a temporary in one instruction now compute the right colours (#280).
- Point-sampled Y16 and R16B16 textures now pass their colours through as the console does (#283).
- Vulkan: a surface is no longer sampled directly as a texture when their row layouts differ (#274).
- Tiny negative vertex inputs now keep their sign, as on the console (#255).
- Fixed-function lighting now uses the console's arithmetic, fixing small shading differences (#224).
- Vulkan: swizzled surfaces with an unusual row pitch no longer corrupt when copied to or from memory (#109).
- Triangles with one vertex behind the camera now draw the way the console draws them (#223).
- Vulkan: a texture sampling a surface that is cleared or drawn to is refreshed instead of showing the old image (#184).
- Vulkan: when colour and depth share the same memory, colour now wins, as on the console (#88).
- OpenGL: swizzled surfaces with an unusual row pitch no longer corrupt when read back (#109).
- Vulkan: depth written over a colour surface now keeps the right values (#91).
- Flat-shaded quads now split along the console's diagonal, so the textures on them no longer shift (#224).
- W-buffered depth now lines up with the console's where a window clip cuts a triangle (#31).
- Triangle fans now take their flat-shaded colour from the right vertex (#13).

### Other

- A vertex sent outside a draw now runs its vertex program, as on the console (#242).
- The GPU's engine-enable register now reads back what the game wrote, as on the console (#188).
- More GPU status registers now read back as the console's do (#190).

Plus internal test-harness work.
