# v0.5.2

A performance release for Halo: Combat Evolved. Signing, the Android 13
minimum and the app name are unchanged from 0.5.1: `adb install -r` installs
this build in place over 0.5.1, keeping your saves, settings and hard disk
image.

### Fixed

- **Halo: Combat Evolved's opening cinematic runs much faster.** It held
  17 fps through the hangar briefing on a Retroid Pocket Nova; it now runs
  at about 29 fps there. Three things were slowing it down: a slower
  texture path the cinematic's colour surfaces were taking every frame, the
  game waiting on the GPU to confirm each occlusion (visibility) test before
  moving on, and the CPU translator recompiling around one floating-point
  instruction more often than it needed to. One of the fixes answers an
  occlusion test as soon as it is queued, using the previous frame's result
  rather than waiting for the real one; very rarely, that can make a visual
  effect such as a flare show up a frame late at a camera cut. Some
  stretches of the cinematic still run under 30 fps. Tracked in
  [#1018](https://github.com/jreinach-alt/hakuX/issues/1018).
