# v0.5.1

A signing, naming and launcher-compatibility release, plus a handful of
stability fixes carried over from X1 BOX.

**Three things to know before installing:**

- **The release key is rotated.** This build is signed with a new key, but
  the old one is kept in the signing lineage, so it installs as an in-place
  update over an official 0.5.0 build: `adb install -r` (or the Play Store
  equivalent) keeps your saves, settings and hard disk image. You do not
  need to uninstall first.
- **It needs Android 13 or later now**, up from Android 10. If your device
  is on an older Android version, stay on 0.5.0 until you can update it.
- **The app's display name changes to hakuX CE** (Community Edition), from
  "hakuX (fork)". The package name (`com.jreinach.hakux`) is unchanged, so
  this is an in-place update, not a new install; a frontend already wired up
  to launch the old name's activity still finds it, since that is keyed by
  package and activity, not the label shown in a launcher.

### New

- **A new app icon.** An adaptive icon with a themed (monochrome) layer, so
  it follows your launcher's icon theme on Android 13 and later.
- **Launching from a frontend, confirmed on a real device.** ES-DE, Daijisho,
  Pegasus and the stock Android launcher (tested as the AYN odinlauncher
  variant; the Retroid variant is not yet tested) all launch and relaunch a
  game. Daijisho and Pegasus list hakuX CE directly through their own
  installed-app views; ES-DE needs the two configuration files it always
  has. See [`docs/frontends/`](https://github.com/jreinach-alt/hakuX/tree/master/docs/frontends)
  for the tested write-up of each.

### Fixed

Carried over from X1 BOX, the project this one is ported from:

- **A game with corrupt or out-of-range audio data no longer closes the
  emulator.** A bad voice is skipped instead, and out-of-range ADPCM audio
  plays instead of producing noise.
- **A texture pointing outside video memory draws blank** instead of
  aborting the emulator or reading past the end of memory.
- **A corrupt pipeline cache is discarded and rebuilt** instead of crashing
  the app at start.
- **Missing audio device is no longer fatal.**
- **The setup wizard rejects a flash BIOS file that is not 256 KB, 512 KB or
  1 MB**, instead of accepting one that will not work.
