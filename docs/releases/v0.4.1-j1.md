# v0.4.1-j1

A frame-rate fix for v0.4.0-j1. It contains one change; everything else is
exactly [v0.4.0-j1](v0.4.0-j1.md).

**Two things to know before installing:**

- It installs **alongside** an official hakuX build rather than replacing it,
  and upgrades v0.4.0-j1 or any earlier fork build in place. Nothing is
  uninstalled and no saves are at risk.
- Launching it from ES-DE still needs the two configuration files in
  [`docs/es-de/`](https://github.com/jreinach-alt/hakuX/tree/master/docs/es-de).

### Fixed

- **In-game frame rate collapsing to 1-3 fps after a few minutes.** In
  v0.4.0-j1 a game could start at full speed and then slow to a crawl while
  its menus and FMV still ran at 59 fps. It was reported in Grabbed by the
  Ghoulies, RalliSport Challenge 2 and Conker. Each time the renderer reused a
  render-target slot, it dropped the slot's guest-memory access watch without
  releasing it. Every guest TLB fill walks that list, so the cost grew for as
  long as the game ran. The watch is now released before the slot is reused.
  ([#311](https://github.com/jreinach-alt/hakuX/issues/311))

### Measured

240-second hands-off runs reading the in-app FPS overlay, on an AYN Thor and a
Retroid Pocket Nova. Each figure is the median frame rate from 90 to 240 seconds.

| title | v0.4.0-j1 | v0.4.1-j1 |
|---|---:|---:|
| Dead or Alive 3 | 2 | **52** |
| Jet Set Radio Future | 27 | **57** |
| Galleon | 28 | 29 |
| Crimson Skies | 29 | 29 |
| Grabbed by the Ghoulies | 1-3 (reported) | **29** on both devices |

No run logged a crash.
