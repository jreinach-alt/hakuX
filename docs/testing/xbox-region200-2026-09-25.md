  `TRAPPED_ADDR` (75 observations), `CSV0_C`, `CHEOPS_OFFSET`, `CONTROL_0`,
  `CONTROL_1`, `SHADOWCTL` (289), `TEXPALETTE0`.

  way):** `NSOURCE`, `CSV1_B`, `ANTIALIASING`, `BLEND`, `CONTROL_2`,

  on silicon and 0 on hakuX. No pixel consequence is known.

## What the instrument cannot see

`DumpDiff` lists a register only when it changes inside a test's bracket.

- A hole bit silicon holds constant is visible only through a register that
  moved for another reason. That is how `ZCOMPRESSOCCLUDE`'s bits 1-2 and
  `SURFACE`'s bit 0 show up.
- NOT SEEN means no evidence. It does not mean zero.

**Instrument defect, found on the dry run and worked around in the judge, not
the XBE.** `DumpDiff` formats the label into `char line[64]`. Long
`Suite::Test` names are truncated, and the BOOT_0 canary line is glued onto
them. 239 of the 800 labels were cut.

The parser names each test from the log's `Starting [k/N]` line, consumes
that line once, and checks glued canaries. The patch in
`docs/testing/patches/pgraph-per-test-instrument.patch` still has the
64-byte buffer. Anyone rebuilding the instrument should widen it.
