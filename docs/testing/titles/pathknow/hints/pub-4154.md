# 4154xxxx titles (Galleon, Shin Megami Tensei: NINE)
Seen: Galleon (41540004; blocked by the owner, runs not expected), Shin Megami Tensei: NINE (41540002).
- Galleon: the SCi logo, then "Please press the START button to begin". The title times out fast into an attract demo behind a ~2.5 min "Loading..." at 0 fps: press START as soon as the title shows. START also selects: the save list "Select a save game" A / B / C (slot A), then New Game / Options / Clear Save Game (New Game).
- Galleon: loading, the ship intro and cutscenes advance with A; play starts on the deck tutorial "Turn Rhama by using the left thumbstick" (STICK:left/right turns him).
- SMT NINE: Japanese-only menus. Its name keyboard with an empty given name is NOT gameplay and will not accept an empty name; a name must be typed and confirmed first (the confirm key, likely 決定, is unverified).
