# Sega titles (5345xxxx)
Seen: Sonic Heroes (5345002B), Super Monkey Ball Deluxe (53450038), Spikeout: Battle Street (53450029), ToeJam & Earl III (5345000F), Gunvalkyrie (USA disc file 5345000B; canonical id 49470017). The ESPN NFL/NBA/NHL/College Hoops 2K5 and ESPN 2K4-era sports titles, Sega GT 2002, Crazy Taxi 3, World Series Baseball and Shadow the Hedgehog have no route evidence: use these conventions and global.md.
- Game Data prompts come right after the title, with the right answer lit: "There is no Game Data ... Create Game Data 01?" then "Game Data has been created ... press A" (Sonic Heroes); "There is no Game Data on your Xbox console. Please press A." then "Do you want to save Game Data?" YES (SMB Deluxe). A each.
- With Game Data on the disk: a slot strip (No.01 lit, A) and Start / Delete / Cancel (Start lit, A) (Sonic Heroes). Never pick Delete.
- Every default on the way to play was right in Sonic Heroes (1P PLAY, STORY, TEAM SONIC) and SMB Deluxe (Main Game, Story Mode, slot 1 "Start the game from the beginning").
- name_entry: SMB Deluxe: A types a letter, START jumps to END, A, then "Are you sure?" Yes (A). Spikeout's player keyboard is different: START TYPES a letter; UP twice reaches Done, A.
- START in gameplay pauses: Sonic Heroes (Continue / Restart / Quit), SMB Deluxe (Continue game / Retry / ...), ToeJam & Earl III (toggles a PLAYER STATS panel). Close it once and never START in play again.
- SMB Deluxe: a fresh game goes straight into stage 1-1 (tilt with the left stick). After a goal it shows Stage Select (rotating camera); there A, B, stick and D-pad do nothing on this build, only START (a pause popup). Stage Select is not gameplay.
- Spikeout: "PRESENTED BY SEGA" video (START skips), "Please press START to begin." (START), Player Selection (A), Main Menu Story (A), "1. Reunion" (A), story videos and a "SPIKER'S CAMP" card (A skips; the videos may show as green blocks), then a dock fight with health bar and K.O. counter.
- ToeJam & Earl III: ONE PLAYER GAME, STORY MODE, character select (ToeJam), his intro, the ship over Earth, a black load, then level 1 on a stone circle (HUD up). A jumps.
- Gunvalkyrie: START/A rounds reach play in about 7-8 rounds; spare rounds there are pause + Continue. Advisor tutorial boxes dim the scene with a yellow down-arrow: A on each.
