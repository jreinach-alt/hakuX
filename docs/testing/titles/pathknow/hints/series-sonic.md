# Sonic (Sega)
Seen: Sonic Heroes (5345002B). Shadow the Hedgehog (53450086): no evidence.
- Sonic Heroes boot: Sega / Sonic Team logo (A), a Sofdec/ADX card (A), the Dolby logo (A did nothing; START skipped it), then the title art "Press START" (START).
- New disk: "There is no Game Data ... Create Game Data 01?" (Create lit, A), "Game Data has been created ... press A" (A). With data: the No.01 slot strip (A), Start / Delete / Cancel (Start lit, A).
- Main Menu 1P PLAY, STORY, TEAM SONIC: A on each lit default. The team's story cutscene (~85-90 s if left alone) skips with A. NOW LOADING, then Seaside Hill with score, time and rings: gameplay.
- Never START in a level: it opens PAUSE (Continue / Restart / Quit) and a run that did so sat paused for 10 min; an A there did not reliably resume. Continue is lit; START to close it is untested.
- Seaside Hill: hold STICK:up to run, A to jump. About 20 s in, a stone block can wedge the team: score and rings frozen while the clock runs = stuck, still gameplay.
- Formations: Y and B cycle Speed / Fly / Power (the leader's circle colour: blue, yellow, red). At a wall in Fly, release the stick and tap A to climb, then nudge forward; at a block signed POWER, switch to Power and punch with X.
