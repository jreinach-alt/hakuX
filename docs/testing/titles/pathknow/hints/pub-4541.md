# EA titles (4541xxxx)
Seen: Burnout 3 (4541005B), Burnout Revenge (45410076), Battlefield 2: Modern Combat (45410062), Black (45410083), 007: Nightfire (45410026), GoldenEye: Rogue Agent (4541005D), 007: Agent Under Fire (4541000D), Buffy the Vampire Slayer (45410012), SSX Tricky (45410004). FIFA, Tiger Woods, Fight Night, NFS and the other EA titles have no route evidence: use these conventions and global.md.
- publisher_logo: RenderWare and EA logos skip with A (Battlefield 2: MC). Burnout 3 shows ~20 s of RenderWare and ~40 s of attract video before its title.
- title_screen: "PRESS START" / "Press START to continue" / "PRESS ANY BUTTON": START (Burnout 3, Burnout Revenge, GoldenEye: RA, Black, Nightfire).
- Most of these ask for a profile before the main menu (Burnout 3, Burnout Revenge, GoldenEye: RA, Black); Nightfire and Buffy do not. On an empty disk choose NEW / Create.
- name_entry: EA keyboards come pre-filled. Black and Burnout 3/Revenge put the cursor on DONE: press A once and touch nothing else (Black's first run typed "KELLAR J. 1K UAA1AK" under stick + A).
- GoldenEye: RA's keyboard starts on a letter; START does nothing there; STICK:right moves one key per flick to OK (about ten, it stops at the end), then A.
- Battlefield 2: MC's CAMPAIGN NAME keyboard: A types; the stick and START do nothing; the D-pad moves it (LEFT wraps to BACKSPACE, DOWN twice reaches ENTER), then A.
- save_load_prompt defaults differ: Burnout 3 "save your profile?" sits on NO (move up to YES, A); Burnout Revenge's Autosave prompt and Battlefield 2's "Do you want to save?" sit on Yes. Read before A.
- Long unskippable videos are common: Black's opening credits (~2 min) and mission briefing (~2.5 min; A, BACK, Y and START did not skip it), GoldenEye: RA's briefing (~65 s), Burnout 3's Race Training (~110 s). Re-read, do not press.
- Battlefield 2: MC: PLAY CAMPAIGN, CREATE CAMPAIGN, the name keyboard, the save prompt, PLAY FIRST MISSION; a ~2 min load with a tank still and a briefing video (A skips); a Help box "Press A to continue, Press B to disable help": B. Then first person in a snowy square at night.
- Black: "PRESS START" (START), the credits video, then (with a profile) START MISSION and NORMAL (A each); the first mission starts in a ruined building ("FIND THE SHOTGUN").
- SSX Tricky: after the menus a run showed only a black frame with an FPS counter: not gameplay (unknown).
- Series detail: series-burnout.md, series-007.md, series-goldeneye.md, series-buffy.md.
