# Midway titles (4D57xxxx)
Seen: Arctic Thunder (4D570002), Gauntlet: Dark Legacy (4D57000E). Mortal Kombat (Deadly Alliance, Shaolin Monks, Armageddon), Area 51, Defender, Freaky Flyers, Blitz and the rest have no route evidence.
- Arctic Thunder: the "Snowmobile Renegades" intro (START ends it); title START / OPTIONS (A on START); SELECT GAME MODE, RACE lit (A).
- Arctic Thunder PLAYER SELECT: A joins player 1; the D-pad does nothing there; push the left stick down to DONE, then A.
- Arctic Thunder: SELECT A DRIVER (A), the track (A), a load, then the race (position 8 of 8, a checkpoint countdown). A is the throttle; RT does nothing. An idle sled runs out of time: TIME IS UP is not gameplay.
- Gauntlet: Dark Legacy: START/A rounds reach the wizard in the dungeon after about 8 rounds. A tutorial scroll over the live 3D view ("I have summoned to my tower ... Press A Button when done") ignores START: press A. Then never START: it opens the pause menu (its Audio page).
