# The King of Fighters (SNK)
Seen: KOF: Maximum Impact - Maniax (534E0007). The King of Fighters 2002 (534E0006): no evidence.
- KOF MI: START ends the intro video. New disk: "OPTION DATA CANNOT BE FOUND ... CREATE NEW OPTION DATA?": YES saves it (A); NO leads to "BEGIN GAME PLAY ANYWAY?" with the cursor on NO. With data: "OPTION DATA ALREADY EXISTS ... LOAD OPTION DATA?" YES lit (A), then an OK box (A).
- KOF MI: on these boxes the D-pad moved the cursor on one and not the next: re-read the highlight before every A.
- KOF MI: a START button on black (START), MAIN MENU with STORY lit (A), CHARACTER SELECT (A, A, A), a load, the opponent's entrance, round 1 with timer and both health bars: gameplay. Story mode draws different opponents and stages.
- A screen with the CPU's "WINNER" / "PERFECT" and the player down is a lost round, not gameplay.
