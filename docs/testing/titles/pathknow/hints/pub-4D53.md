# Microsoft Game Studios titles (4D53xxxx)
Seen: PGR (4D530003), PGR2 (4D53004B), Forza (4D53006E), RalliSport Challenge 2 (4D530039), Halo (4D530004), Halo 2 (4D530064), MechAssault 2 (4D53006B), Brute Force (4D53001E), Azurik (4D530007), Blood Wake (4D530010), Midtown Madness 3 (4D53002A), Grabbed by the Ghoulies (4D530053), Crimson Skies (4D530021), Fuzion Frenzy (4D530002), Conker (4D530051), Phantom Dust (4D530046), Blinx (4D530013), Blinx 2 (4D530065). Series files: halo, gotham, rallisport, mechassault, blinx.
- intro_video: START ends it in PGR, Brute Force and Midtown Madness 3; A in Azurik and RalliSport 2. Brute Force loads ~100 s before its first menu.
- title_screen: "Press START" waits; MechAssault 2's stays up 60 s+ with no attract. Azurik's falls into an attract demo that still says "Press START to play": START works there.
- Many ask for a profile, driver or slot first, and the default is right: PGR create new driver, RalliSport 2 SELECT PROFILE, Midtown Madness 3 SELECT A PROFILE, Brute Force SELECT PROFILE (DEFAULT), Forza PROFILE SELECT (Default), Halo ENTER NAME (New001), Ghoulies "Choose A Game" slot 1 then a keyboard ("My Game", DONE lit).
- Brute Force: every choice on the way is the lit row (START / DEMOS: A on START, CAMPAIGN, CAMPAIGN TYPE, profile, New Campaign, name CAMP001 DONE, STANDARD, Tex); JOIN CAMPAIGN asks "Press START to begin": START. A stick flick moved two rows: re-read.
- Brute Force tutorial cards (BASIC CONTROLS, HEADS-UP DISPLAY) pause play: Y skips them all, A one.
- Blood Wake: Story Mode, Create Game; CREATE GAME's focus starts on Select Storage (A keeps the hard disk), stick down to the slot list, NEW GAME; every screen after (overwrite prompt, sketchbook pages, difficulty, boat, briefing, MISSION GOALS) takes A; then the boat on the water.
- Midtown Madness 3: a driving-safety warning (A), SELECT A PROFILE (A), WORK UNDERCOVER, a city, a job video (A skips), PIZZA DELIVERER, the default car; the mission card ends on "PRESS START" (START). START in the race pauses (RESUME RACE lit: A).
- Azurik: FMV (A), "Press START to play" (START), save screen "Start New Game" (A), an in-engine opening and Arena boxes "... Continue (A)": A. In play A is jab, so a spare A is harmless.
- Ghoulies: the storybook intro is pages and cards that wait for A (use A, not START: a START that reached the hallway paused it); then tutorial cards (A). In play the right stick attacks.
- Crimson Skies: A through the intro and the first tutorial prompts reaches flight; centred sticks fly level; later tutorial prompts also take A.
- Fuzion Frenzy: alternating START and A for ~90 s reaches a minigame; no menu to navigate.
- Phantom Dust: about 13 START/A rounds reached the first explorable room (player in view, minimap).
- Conker: the front end is multiplayer (Xbox Live / System Link / Dumbots / Profiles). Xbox Live answers "Connection to Xbox Live lost. Cannot sign in" and loops: choose Dumbots or a single-player entry (not yet found on screen).
- Driving titles: RT throttle, LT brake/reverse; triggers rest at min (a half-held LT keeps a RalliSport 2 car at 0 mph).
- Avoid Xbox Demos (PGR2's last menu item).
