# Project Gotham Racing (Microsoft)
Seen: Project Gotham Racing (4D530003), Project Gotham Racing 2 (4D53004B).
- PGR: intro video, Kudos card, Bizarre Creations logo: START skips each.
- PGR "load or create new": on a new disk create new driver (A), setup with the defaults (name Player, plate GOTHAM) continue (A), save to hard disk (A), "progress will be saved automatically" (A). With a driver saved "load existing driver" is lit: A, load from hard disk (A), the driver (A).
- PGR main menu opens on arcade race: one step up to quick race (A); skill easy, San Francisco, MINI Cooper S, AUTO (A each); a flyby (A skips part); the grid countdown. Hold RT from the countdown.
- PGR2: Bizarre Creations logo, intro video (START skips), title "Play PGR 2 / PRESS START" (A works); menu Start Player's Game (or Create New Profile) / Profile Manager / Instant Action / Xbox Demos.
- PGR2's menu auto-repeats, drops taps while animating and stops at Xbox Demos: hold right to the end, then one short tap left to Instant Action (A). B on the menu returns to the title.
- PGR2 Instant Action: a load, the "Welcome to Florence" flyby (ends by itself), then the race (LAP 1 of 2, a 5-minute clock).
- Both: a car at 0 mph on the grid is not yet gameplay: hold RT.
