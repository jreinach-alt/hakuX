# Buffy the Vampire Slayer
Seen: Buffy the Vampire Slayer (45410012, EA id, Nova). Buffy the Vampire Slayer: Chaos Bleeds (56550005, Thor): no evidence.
- Boot: FOX Interactive, an intro video (START skips it), an in-engine opening that draws a HUD (not gameplay), the Buffy title "Press START" (START).
- Main menu Start Game / Load Game / Options / Extras: one stick or D-pad pulse moves one row or two; the lit row is the brightest; re-read after every move.
- Start Game ("Launch a New Game on your Xbox Hard Disk called BUFFY n", A), DIFFICULTY with Normal lit (A or START), "Summoning" (loading), a card "Spanish Mission, Outskirts of Sunnydale", then the canyon with a flame heart and bars top left: gameplay.
- The game keeps at most 10 saves; each Start Game adds one. With 10 on the disk Start Game shows "... only allows 10 saved games ... Press A to continue" and A returns to the menu: use Load Game, a BUFFY save, the checkpoint "Spanish Mission, Canyon". On the Load Game screen Y is DELETE: never press Y there.
- START in play opens PAUSE (Resume / Options / Quit, Resume lit): A resumes.
- The camera can swing up to the night sky with Buffy out of view: LT resets it. Still gameplay.
- Controls (Configuration 1): left stick move, B Jump, A Kick, X Punch, Y Use, L Look, R Target. The canyon's "Run and press B to jump between ledges" gap has not been crossed here; the stream bed below it is a pit.
