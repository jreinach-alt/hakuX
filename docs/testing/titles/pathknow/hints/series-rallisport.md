# RalliSport Challenge (Microsoft)
Seen: RalliSport Challenge 2 (4D530039). RalliSport Challenge (4D53000F): no evidence.
- RSC2: logo videos (A skips), "PRESS START TO BEGIN" (START), SELECT PROFILE with the saved profile lit (A). On a new disk: Create new Profile and a letter grid where START TYPES a character: move to Done with the D-pad, then A.
- RSC2 MAIN is a carousel that starts on CAREER, auto-repeats when held and stops at both ends: use short D-pad taps (one entry each). Tap left until it stops at TIME ATTACK (seven taps from anywhere), A.
- RSC2 Time Attack: RACE TYPE CROSSOVER, a track (Australia / Copperhead), RACE SETTINGS, a car, START RACE (A each; a press during a load can be swallowed: re-read and repeat). A flyover, then the race clock runs.
- RSC2: the car starts nosed into the first barrier: hold LT fully to reverse off it, then RT and steer. A half-held LT holds the car at 0 mph.
