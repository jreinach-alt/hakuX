# Midnight Club (Rockstar)
Seen: Midnight Club 3: DUB Edition (54540079). Midnight Club II (54540008): no evidence.
- MC3's boot takes no input: Rockstar logos (~6-20 s), the intro video (~25-80 s), trademark pages, a fly-in, then the title "Press START to begin" (~107-155 s after launch), after which the attract video loops. Press nothing until the title; then START (A does nothing there).
- After START, "Checking saved games", then the profile list. New disk: CREATE PROFILE (A), "Enter Profile Name" with "Player 1" and ACCEPT lit (A), "Saving progress and settings". With profiles, the last-used one is lit and the list wraps: take it (A).
- Main menu Career / Arcade / Networking / Race Editor / Options: the stick jumps a varying number of rows; one quick DOWN tap moves one row, Career to Arcade (A).
- Arcade: "San Diego / Cruise / Players: 1" (START or A), a settings screen with everything Default (START or A), "Start" (A), LOADING, then a parked car by "SIX-ONE-NINE CUSTOMS" with minimap, tach and speedo: gameplay; RT drives.
- A static showroom view of the car with no HUD can appear before that: wait for the HUD, it is not gameplay.
