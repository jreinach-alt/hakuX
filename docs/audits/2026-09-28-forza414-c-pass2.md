## LOW 1: `uniform_hashes_stale` is file-static

Still as written (`shaders.c:1352`, set at 1422, read at 1435, cleared at
1441). Pass 1's failure scenario was "none that renders wrong", and a
re-check agrees:

- The flag starts `true`, so the first clean draw of the process always
  uploads.
- The only path where the flag does not force an upload is a renderer that is
  rebuilt while the flag is `false`. In that case the zeroed
  `last_*_uniform_hash` is compared against a real `fast_hash`. A skipped
  upload would need a 64-bit hash of exactly 0 on both layouts.
- The flag is set and read only in `pgraph_vk_update_shader_uniforms`, on the
  drawing thread, which is the same thread that owns the hashes it qualifies.
  So there is no race.
- A `shader_binding` switch between two clean draws compares the hashes of
  different layouts. That is the behaviour master already has, and this PR
  does not change it.

This remains a quality point, and it does not block the fold.

## LOW 2: the arms ran 79f0102478, not the head

Checked line by line. The only lane code commit on `hw/` after B that is not a
merge is 24f56f1981 (`git log --no-merges 79f0102478..d433d6af74 -- hw/`
also lists 2f38c02487, 61e7a0d326 and ecf5e05dd2, all from master via
#413/#414 merges, as pass 1 said). What 24f56f1981 changes in
`clear_rect_clipped`:

- The four `GET_MASK` reads go into the locals `x0, x1, y0, y1`, which are
  `unsigned int`, the same type as the out-pointers. Before, they went
  straight through `*xmin..*ymax`.
- The clip `MAX`/`MIN` calls are the same, with the same operands, the same
  `cw`/`ch` guards and the same `cx + cw - 1` bound.
- The four stores happen once, at the end. The return
  `x0 <= x1 && y0 <= y1` reads the same values the old return read through
  the pointers.
- Aliasing cannot differ. Both callers (`draw.c:7273` and `draw.c:7360`) pass
  four distinct stack locals.

Both callers therefore get the same outputs and the same return for every
register and clip state. The verdicts registered for B hold for the head, and
no new arm is needed.
