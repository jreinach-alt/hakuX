## Method

I built the lane's own harness (`docs/lanes/flatlm13/rewrite_edges.c`) against
three copies of `prim_rewrite.c`: `origin/master`, the arm-measured head
`49ecb3e0e7`, and this head. Each was built twice, once with
`.no_adjacency = 0` (a geometry stage exists: Vulkan, desktop GL, GLES with
GS) and once with `.no_adjacency = 1` (GLES without a geometry shader). The
harness emits the line-mode QUADS(8), QUAD_STRIP(6) and POLYGON(5/3/2) streams
for every combination of flat/smooth and first/last provoking.

| comparison | result |
|---|---|
| master vs arm-measured, geometry stage | differs on the flat rows only: (2,3)→(3,2), (1,3)→(3,1), (4,0)→(0,4), (2,0)→(0,2), as intended |
| arm-measured vs head, geometry stage | **identical** |
| master vs head, no geometry stage | **identical** |
| arm-measured vs head, no geometry stage | differs on exactly the four flipped flat rows (the pass-1 regression, now removed) |

## M1 (MEDIUM): no longer occurs

Scenario: a flat line-mode QUADS on Android GL without geometry shaders. The
edge (v2,v3) was emitted as (v3,v2), so GLES's last-vertex provoking rule took
v2's colour.

On this head, `flat_line_first()` returns `flat_shading && !no_adjacency`, and
all three `*_line()` call sites in `rewrite_indices()` pass it. On the no-GS
path the stream is byte-identical to master for every primitive and both
provoking settings, so the edges (v2,v3), (v1,v3) and (v4,v0) keep their
master orientation. `no_adjacency` is set only by `gl/draw.c:830`
(`!gl_geometry_stage_available(r)`). The Vulkan `PrimAssemblyState`
initialisers are designated and leave it false. So Vulkan keeps the flip, and
the harness shows its stream is unchanged from the arm-measured head. The
FLAT COLOUR comment now says why the gate is there, as pass 1 asked.

## L1 (LOW): addressed

`emit_edge_flat()` now calls `emit_line_pv(r, a, b, p)` when flipping, so
there is one copy of the orientation rule. At every call site `p` is `b`, so
`emit_line_pv` emits (b,a), which is what the old `b == p` branch did. A
degenerate `a == b` gives the same pair either way.

## L2 (LOW): unchanged, as expected

Reversal coverage on desktop GL's native line rasteriser is still unmeasured.
This was a recorded limit with no remedy, and it is not a fold blocker.
