Head audited: `5113aa809a` (lane/pshaniso284). Diff read: `git diff origin/master...HEAD`
with origin/master at `02374a6847` (#379 has folded, so the diff is this lane's
edits only): `psh.c`, `psh.h`, `vk/texture.c`, `gl/texture.c`, `psh_differ/differ.c`,
two prediction files, lane notes, and the regenerated nv2a index.

Result: **1 MEDIUM, 2 LOW, no HIGH.** Next label: `needs-remediation`.

## MEDIUM-1: the host sampler drops anisotropy for stages the shader does not probe

`vk/texture.c:2469` and `gl/texture.c:635` force host anisotropy to 1 for every
texture with MIN = MAG = BOX_LOD0. The shader takes the probes only for a subset
of those stages:

- `psh.c:547-553` sets `tex_aniso[i] > 1` only when `!tex_bytes16[i]`;
- `psh.c:3287` emits the probe loop only for `PS_TEXTUREMODES_PROJECT2D`, 2D,
  non-cube, non-shadow, non-convolution.

Every other BOX_LOD0 stage with `MAX_ANISOTROPY > 0` now gets neither the host
filter nor the probes. That covers cube maps, 3D textures, shadow maps, every
dependent-read and dot-product mode (BUMPENVMAP, DPNDNT_AR/GB, DOT_ST/STR_3D/
STR_CUBE/RFLCT_*), and point-sampled Y16 / R16B16, which `psh.c` leaves out of
the probe model on purpose.

The lane's own policy in `psh.c:541-546` and at `psh_append_aniso_probes` is that
a configuration the model has not measured "keeps the host sampler". The
texture.c edits break that policy for these stages.

**Failure scenario.** A title samples an environment cube map (or an R16B16
point-sampled bump texture, or a DPNDNT_AR lookup) with MIN = MAG = BOX_LOD0 and
TEXCTL0 MAX_ANISOTROPY = 3. It runs on a driver that applies anisotropy under
NEAREST, which is the premise of the texture.c comment. Before this PR that
fetch was host-anisotropic. After it, the fetch is a single point sample, and
the shader emits no probes because it is not a 2D PROJECT2D stage. No capture
on the disc can see this, since the aniso prediction states nothing else sets
MAX_ANISOTROPY above 1, so the arms passing says nothing about it.

**Remedy.** The sampler should drop host anisotropy only when the shader will
take the probes. Put the condition in one predicate that psh.c and both
texture.c files call. It needs the same registers `pgraph_glsl_set_psh_state`
reads:

- TEXFILTER MIN/MAG;
- the bytes16 test (format, sign flags);
- TEXFMT dimensionality and CUBEMAPENABLE;
- the depth format (shadow map);
- the stage's mode from SHADERPROG, which must be PROJECT2D.

All of these are readable from `pg` in texture.c. If the mode test is left out,
the dependent-read and dot-product modes keep the defect. In that case the
remediation comment must name the gap.

## LOW-1: the footprint derivative includes the per-pixel tie bias

`psh_append_aniso_probes` takes `dFdx/dFdy` of `aUV`, which already has
`texelTieBias<i>` added. Under #282's tie rule (vulkan, fixed function, smooth
shading) that bias is `texelTieBias.y * texelTieV(vtxT<i>)`, which varies per
pixel. A quad that straddles a change in `texelTieV` adds the bias step to `aDy`.
The bias is a sub-texel epsilon, so the effect on `aMaj`/`aMin` is negligible,
but the footprint is meant to be the Jacobian of the texture coordinate. The fix
is to take the derivatives of `tex_remap(pT.xy) / pT.w` before adding the bias.

## LOW-2: the BRDF raw-consumption exemption applies to an invalid BRDF stage

`stage_consumed_raw` (`psh.c:2093`) returns true for stage `i` whenever some
`j` with `j - i <= 2` is BRDF. That includes a BRDF in stage 1, which
`stage_consistent(.., 2, 3, 0, ..)` rejects and emits as NONE. In that case a
point-sampled Y16 / R16B16 stage 0 loses #283's byte split although nothing
reads it raw. Only an invalid shader program can trigger it. The fix is a `j >= 2` guard.

## Checked and clean

- `MAX_ANISOTROPY` is the 2-bit mask `0x30`, so N is 1, 2, 4 or 8. That matches the
  differ's `K_INT 1..8` range, and the loop bound `n / 2` covers
  `aFull / 2 <= N / 2` pairs.
- Probe weights sum to 1: `aFull * aW + (aNf - aFull) * aW = aNf / aNf`. `aNf < 2` is
  a centred pair collapsing to one point at `aNf = 1`. A constant UV gives
  `aMaj = 0`, so `aNf = 1`, a single point, with no divide by zero (`max(aMaj, 1e-9)`).
- `tex_aniso` of a disabled stage is 0 because `ShaderState` is memset in
  `pgraph_glsl_get_shader_state`. The use site tests `> 1`, and the shader key
  stays deterministic.
- Rect textures go through `norm<i>` exactly as in the old `textureProj`
  path. `aSize = textureSize / texScale` is in guest texels for an upscaled
  rect texture and equals `textureSize` otherwise (vk forces `texScale` to 1 for
  swizzled textures).
- The derivatives are taken in the stage's straight-line code, before any
  branch, and every probe is `textureLod(.., 0.0)`. That is legal in the
  non-uniform branches that follow. `dFdxCoarse` is used only on Vulkan (GLSL
  450). GL and GLES take `dFdx`.
- BRDF: `get_sampler_type` returns `sampler3D` for a 3D non-cube, non-shadow
  texture and marks every other case `tex_unusable`. That case is emitted as
  NONE before the switch, so the `texture(sampler3D, vec3)` line never meets a
  mismatched sampler. `stage_consistent` with `dots_needed = 0` is correct,
  because the feeding stages are ordinary reads.
- Both arms PASS on the registered checks (86/86, 74/74). The prediction files'
  `a_ref`/`b_ref` are the two lane commits named in the PR body.
