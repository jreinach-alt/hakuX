## Pass-1 scenarios, re-checked on the head

### LOW 1 (GL renderer, z-buffer ZCLAMP_CULL): still occurs, not a regression

`psh.c:2601-2602` still gates on `!depth_clipping || z_perspective`, and
`depth_needed` is still set only off-GL (`psh.c:317-324`). So on GL a
z-buffered NEARFAR|ZCLAMP_CULL triangle wholly beyond CLIP_MAX still draws.
It drew before this PR as well, and the goldens run on Vulkan. The comment
at `psh.c:2597-2599` still says "the per-pixel clip below already discards
every pixel", which is true on Vulkan only. This is a one-line comment
correction or the gate change pass 1 gave. It can be done after the fold.

### LOW 2 (wireframe triangles tested per edge): still occurs, unmeasured

`geom.c` is not touched by the PR, and `emit_line` still carries each edge's
own two endpoints. So an edge whose two endpoints are both outside is still
dropped, even when the triangle's third vertex is inside. No golden draws
wireframe with NEARFAR, so this needs a hardware capture before it is a
defect. `docs/lanes/cullnf276/NOTES.md` records CULL_IGNORE_W as unmodelled
(line 21) but does not yet record this case.

### LOW 3 (pre-offset z vs post-offset z): still occurs, unmeasured

`psh.c:2604-2610` still compares raw `vtxPos*.z`. The skipped z-buffer ZCULL
branch still clips on post-offset `zvalue`. Neither the comment nor the NOTES
names the assumption. ZMinMaxControl draws no polygon offset, so no golden
can decide it.

## Why this is fold-ready rather than needs-remediation

None of the three is incorrect behaviour on anything the PR measured. LOW 1
is pre-existing GL behaviour that this PR leaves unchanged. LOW 2 and LOW 3
are cases no golden can reach yet: calling either one wrong now would assume
a hardware answer nobody has captured. The arm passed 866/866, with better
12 and worse 0, and the must-not-move suites stayed bit-identical. The
measured code is unchanged since then.

Follow-up, not a fold condition: fix the LOW 1 comment, and add LOW 2 and
LOW 3 to the lane NOTES' unmodelled list so that a future NEARFAR wireframe
or offset golden has them to check against.
