  surface.c:4557-4562, `SURF413_T`, `_FIN`, `_ACC` and `_DO` are all `((void)0)`. `SURF413_HASHED`
  is also `((void)0)` (:2003). Every use is a complete statement, and C99 allows a statement to
  come before a declaration, so the declarations that follow `SURF413_T(_s413);` still compile.

  :195). But every `[surf413]` symbol, including `surf413_resume_*`, sits behind
  `NV2A_PERF_LOG && defined(__ANDROID__)`, and so do its only readers. No symbol is left dangling.
- **`SURF413_DO` arguments.** None of them has a comma at the top level. The final one,
  `g_surf413.fin_ns += ...; surf413_log(pg, r)`, joins two statements with `;`, which is fine
  inside `do { stmt; } while (0)`.
