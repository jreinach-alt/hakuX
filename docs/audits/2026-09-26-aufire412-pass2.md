3. **Overflow pools destroyed in use.** The only runtime reclaim is still

4. **Shared pool array.** `grow_descriptor_ring` still has exactly one call
   site (`shaders.c:507`, the UBO ring), so reclaim leaves the gfx ring's
   count at its base. Holds.
5. **Teardown.** `pgraph_vk_finalize` still calls `pgraph_vk_finalize_textures`
   (`renderer.c:306`) before `pgraph_vk_finalize_shaders` (`renderer.c:308`),
   and `finalize_textures` still asserts `!in_command_buffer` and calls
   `pgraph_vk_flush_all_frames` unconditionally (`texture.c:3307-3311`). The
   pools are reclaimed and `push_ubo_set_count` restored before
   `destroy_ubo_descriptor_resources` runs. Holds.
6. **Grow twice in one call.** The second site (`shaders.c:633-635`) is still
   guarded by `index >= count`, and the `assert` follows both the grow and the
   fallback (finish + flush resets the index to 0). Holds.
