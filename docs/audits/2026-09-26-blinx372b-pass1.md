## LOW

1. **No regression lock on the new tags.** Fragment 51 part I checks only
   `libc:F DEBUG:F hakuX-stderr:E hakuX-crash:V`. A later edit to LOGCAT_SPEC
   can drop `hakuX-stall` and every perflog soak silently loses the site split
   again -- the exact failure this PR fixes. Scenario: a future lane rewrites
   the spec line from an older copy; CI stays green. Fix: add `hakuX-stall:I
   xemu-gpu:I` to the loop at 51-dispatch-hardening.sh:391.
2. **`sites.py` reports comment lines as sites** (draw.c:3462, renderer.c:1446,
   renderer.c:2157 are prose mentioning `pgraph_vk_finish(...SURFACE_DOWN)`).
   NOTES filtered them correctly by hand, but a reader re-running the script
   gets 12 "sites". Fix: skip lines whose stripped text starts with `*`, `/*`
   or `//`.
3. **`workread.py` is brittle**: `'2026-'` is hard-coded into the timestamp
   parse (a soak spanning a year boundary mis-orders), `body.split('Fin:',1)[1]`
   and `re.search(r'S2T:...').group(1)` raise on any xemu-work line lacking
   those fields, and `f = dict(...)` is computed and unused. The histogram key
   is the whole remainder of the line after `Fin:`, not only the Fin fields.
   Bounded: lane-local, read by a person, and the NOTES table it produced is
   consistent with the samples it names.
4. **`run_selftest.sh` writes a fixed `/tmp/blinx372b-selftest.log`** and caps
   the run at 580 s, so its "0 bad" is over a truncated run (NOTES says so).
   CI is the gate of record and is green; quality only.
