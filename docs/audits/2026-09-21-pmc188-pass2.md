### M3 — the framing

Pass 1 asked for four things and all four are present, at all three sites
(`pmc.c:69-95`, the PR body, `NOTES.md`):

1. bits 8 and 12 are **clear**, consistent with idle engines — not a
   contradiction of the header;
2. `nv2a-mapping-programme.md:168` already reads bit 16 as PTIMER;
3. what is unestablished is **bits 20 and 24, and what a busy machine reads**;
4. the machine state the word was measured in is recorded beside the constant,
   with the repeatability-vs-state-independence distinction spelled out.

**Corrected in place, not appended.** `NOTES.md`'s section heading carries the
marker ("*The first version of this section said the header and the measurement
'do not reconcile'. That was wrong*"), so the summary at the top of the file no
longer asserts the withdrawn premise while a correction sits at the bottom.
`git grep -i "do not reconcile"` over the branch now hits only the pass-1 audit
records, which is where it belongs.

**Every cited source checks out.** I read each rather than taking the citation:
`nv2a_regs.h:72-74` (`0x00000200`, `_PFIFO (1 << 8)`, `_PGRAPH (1 << 12)`);
`nv2a-mapping-programme.md:167-168` and `:204` (bit 16 = PTIMER, 992/1024);
`nv2a-probe-pmc-findings.md:127-130` (PTIMER 992/1024, PFIFO 382/2048, PGRAPH
**0**/2048) and `:35` (`BOOT_0` = `02A000A3` as the control in both runs).

And the remediation **corrected the auditor**, which is the part worth

*unrefuted*, not confirmed. `NOTES.md` and the PR body both say it that way. A
remediation that argues with the audit and is right is the outcome this pass is
for.
